# Instagram Codex Web : projet Sugar Nails (bulgare)

Visuels prêts à publier, dans ce dossier :

| Fichier | Format | Usage |
| --- | --- | --- |
| `post-1.png` … `post-5.png` | 1080×1350 (4:5) | Carrousel du post, dans l'ordre |
| `story-1.png` | 1080×1920 | Story 1 : teaser du projet |
| `story-video.mp4` | 1080×1920, 22 s | Story 2 : le site mobile en mouvement |
| `story-2.png` | 1080×1920 | Story 3 : galerie, prix, réservation |
| `story-3.png` | 1080×1920 | Story 4 : appel à l'action |

Pour régénérer après une modification du site ou des textes : `npm run build`, `npx vite preview --port 4173`, puis `node social/instagram/source/render.cjs` (textes et mise en page dans `source/templates.html`).

## Stories : stickers à ajouter dans Instagram

Les zones sont laissées libres pour les stickers interactifs (ils ne peuvent pas être intégrés à l'image).

1. **story-1.png** : sticker mention `@sugar_nails_sofia`.
2. **story-video.mp4** : sticker mention `@sugar_nails_sofia`, musique douce au choix.
3. **story-2.png** : sticker sondage sur le bas des téléphones.
   Question : `Кое ти харесва най-много?` · Réponses : `Галерията` / `Анимацията`
4. **story-3.png** : sticker question sous le bouton rose.
   Question : `Какъв сайт ти трябва?`
   Ou sticker lien vers votre site / WhatsApp si vous en avez un.

Ajoutez ensuite les 4 stories à une story à la une « Проекти ».

Mot-clé du DM (story 4) : les gens écrivent « САЙТ ». Si vous utilisez une réponse automatique, réglez-la sur ce mot.
